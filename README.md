# DataNest — AI & Data Science Study Hub

A responsive, single-page front-end web application created for the Web Application Development Assignment 1.

## Features
- Learning dashboard and progress indicator
- Four-stage Data Science roadmap
- Project ideas with difficulty filters
- Searchable learning resources
- Five-day weekly study checklist
- Quick knowledge quiz with feedback
- Task manager with add, complete, and delete actions
- Browser Local Storage for tasks and weekly progress

## Technology stack
- HTML5 for structure
- CSS3 for styling and responsive layout
- JavaScript for interactivity
- Local Storage for browser-based persistence

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Publish with GitHub Pages
1. Upload `index.html` to the root of a GitHub repository.
2. Open repository Settings → Pages.
3. Set Source to `Deploy from a branch`, select `main` and `/(root)`, then Save.
4. Wait for publishing and use the Visit site link shown in Pages settings.

The application is a static front-end demo. Learning-resource links need internet access. Task lists are saved locally in each browser and are not shared between users.
